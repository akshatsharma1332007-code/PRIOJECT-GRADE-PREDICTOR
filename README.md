# Student Grade Predictor
A supervised machine learning project that predicts student final grades
based on study hours, attendance, previous scores, and sleep hours.
## What I Learned Building This- Data loading and exploration with **Pandas**- Data visualisation with **Matplotlib** and **Seaborn** (EDA)- Supervised ML concepts: features, target, train/test split
- Training and evaluating **Linear Regression** and **Random Forest** models- Interpreting model accuracy using MAE and R2 score- Feature importance analysis
## Technologies
Python | Pandas | NumPy | Matplotlib | Seaborn | scikit-learn
## Results
| Model | MAE | R2 Score |
|------------------|------|----------|
| Linear Regression | ~2.3 | ~0.97 |
| Random Forest | ~1.9 | ~0.98 |
